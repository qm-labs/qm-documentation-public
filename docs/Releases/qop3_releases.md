# OPX1000 (QOP 3) Releases

Here you can find release notes and version files for the latest version of {{ requirement("OPX1000",3) }}

!!! Note
    Attempting to use qm-qua <1.2.2a3 with QOP 3.3.0 or higher will result in the inability to fetch results from the OPX1000.

## QOP 3.4.x

### QOP 3.4.0

- To download QOP 3.4.0, please contact QM support.
    - Due to the first two issues in the [release notes](../../hidden_pages/QOP34x.md#known-issues-in-34x), the download link is not publicly available.
    - A new version which fixes these will be ready soon and will be available for download.
- [QOPA](qopa_releases.md) 1.2.1 (or newer) must be installed before installing QOP 3.4.0.
    - It'll be installed automatically when upgrading directly from QOP 3.2.x.
- Please see [the release notes page](../../hidden_pages/QOP34x.md) for more information about this version.
- Use with `qm-qua==1.2.3a1` or newer.


## QOP 3.3.x

### QOP 3.3.0

- QOP 3.3.0 can be downloaded from [here](https://qmpublic.s3.amazonaws.com/QOP/QOP3.3.0/1741076350-eu3da3/QOP3.3.0.tar.gz.age).
- Please see [the release notes page](../../hidden_pages/QOP33x.md) for more information about this version.
