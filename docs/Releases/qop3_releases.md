# OPX1000 (QOP 3) Releases

Here you can find release notes and version files for the latest version of {{ requirement("OPX1000",3) }}


## QOP 3.3.0

* QOP 3.3.0 can be downloaded from [here](https://qmpublic.s3.amazonaws.com/QOP/QOP3.3.0/1741076350-eu3da3/QOP3.3.0.tar.gz.age).
* Please see [the release notes page](../../hidden_pages/QOP33x.md) for more information about this version.
* Use with `qm-qua==1.2.2a3` or newer

!!! Note
    Attempting to use qm-qua <1.2.2a3 with QOP 3.3.0 will result in the inability to fetch results from the OPX1000.
