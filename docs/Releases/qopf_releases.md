# QOP Firmware (QOPF) Releases

Here you can find release notes and version files for the latest version of QOP Firmware (QOPF).

!!! Warning
    Installing QOPF flashes your firmware. 
    Any interruption such as power loss/change of cluster parameters/reclustering 
    can corrupt the firmware and require factory service.
    Please follow the on-screen instructions prompted by the installation, and feel free
    to contact QM support with any questions you might have.

## QOPF 1.1.0

QOPF 1.1.0 can be downloaded [here](https://qmpublic.s3.amazonaws.com/QOPF/QOPF1.1.0/1762943732-tufky1/QOPF1.1.0.tar.gz.age)
